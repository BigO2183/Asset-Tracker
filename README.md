# SimpleStock v25.2 — Core Screen Polish

Keeps the v25 design and improves the four most important screens.

## Inventory
- calmer filter hierarchy
- cleaner item-count line
- tighter inventory cards
- better item / price / status hierarchy

## Sales
- tighter KPI cards
- less wasted empty space
- cleaner recent activity
- repetitive no-op change text is shortened

## Reports
- exports separated from metrics
- Potential Sales Value renamed to Inventory Value
- lighter summary cards
- cleaner inventory-aging section

## Add / Edit Item
- full-screen editor on mobile
- clearer field grouping:
  - Basic Info
  - Pricing
  - Listing & Storage
  - Notes
- sticky bottom action bar
- Save remains primary
- Mark Sold stays secondary
- Duplicate stays tertiary

No backend behavior was intentionally changed.
