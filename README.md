# SimpleStock v25.4 — Profit, Shipped & Returns

## Added
- Potential profit automatically shown on reseller inventory cards: Asking Price - Paid Cost
- Shipped status throughout reseller status controls
- Returns section with return count, refund total, and needs-review count
- Mark Returned workflow captures date, refund, reason, condition, and notes
- Returned items open from the Returns section
- Sales and reports treat Sold + Shipped as completed sales
- Shipped and Returned are excluded from active inventory

## Return workflow
Open a Sold/Shipped reseller item → Mark Returned → enter return details → Save Return.
